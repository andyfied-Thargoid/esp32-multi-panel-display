# Standalone ESP32 CYD Clock

Standalone 24-hour clock firmware for the ESP32-2432S028C/CYD board.

- ILI9341 landscape display (320x240)
- Black text on a white background
- Minute-only clock redraw
- UK timezone and NTP synchronization
- Serif clock/date and monospaced service messages

Copy config.h.example to config.h and set Wi-Fi credentials. config.h is ignored by Git.
